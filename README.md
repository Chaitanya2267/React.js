# React Learning Journey 🚀

A collection of React projects built while learning React fundamentals and modern development concepts. This repository documents my hands-on practice with React, covering topics from basic components to state management, routing, context API, and custom implementations.

## 📌 About

This repository contains small projects and exercises created during my React learning journey. Each folder focuses on a specific concept and serves as a practical implementation of what was learned.

More projects and advanced topics will be added as the learning journey continues.

## 📂 Projects Included

### 01. Basic React
Introduction to React fundamentals, components, and project structure.

### 02. Counter
A simple counter application demonstrating state management using `useState`.

### 03. Tailwind Props
Practice project showcasing React props and Tailwind CSS integration.

### 04. Background Changer
Interactive application for dynamically changing background colors.

### 05. Password Generator
Password generator built using React Hooks and state management.

### 06. Currency Converter
Currency conversion application utilizing API integration and React concepts.

### 07. React Router
Project demonstrating client-side routing using React Router.

### 08. Mini Context
A simple implementation of React Context API for state sharing.

### 09. Theme Switcher
Theme switching application using Context API and component state.

### Custom React
A basic custom implementation to understand React's core working principles.
